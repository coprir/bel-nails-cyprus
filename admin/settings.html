Deputy Content Approval

When ON (recommended), anything a Deputy submits — manual designs or Instagram imports — waits as Pending Approval until you approve it from the Portfolio page. When OFF, an authorized Deputy can publish directly to the public Lookbook.

Master-Only Controls

Payments, database configuration, Instagram app credentials, deployment and hosting settings are intentionally not exposed here — they live only in this project's Vercel environment variables, which no admin account (Master included) can read or change from this dashboard. This is a deliberate security boundary, not a missing feature.
